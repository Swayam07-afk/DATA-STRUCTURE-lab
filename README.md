Data Structure Lab
📌 Project Overview
This repository contains C programs developed as part of the Data Structure Lab. It demonstrates the implementation of fundamental data structures and algorithms, including sorting, queues, stacks, trees, and contact management using linked lists.

🎯 Objectives
To understand fundamental data structures and their operations.
To implement data structures using the C programming language.
To learn sorting and data organization techniques.
To develop logical thinking and problem-solving skills.
To gain practical experience in writing and executing C programs.
📂 Programs Included
Sr. No.	File Name	Description
1	Bubblesort.c	Implements the Bubble Sort algorithm to sort elements in ascending or descending order, depending on the program logic.
2	Queue.c	Demonstrates queue operations such as insertion (enqueue) and deletion (dequeue).
3	conatctlist.c	Demonstrates contact list management using data structures.
4	conatctmanage.c	Implements contact management operations such as adding, viewing, searching, or updating contacts, depending on the implementation.
5	stack.c	Demonstrates stack operations such as push, pop, and peek.
6	tree.c	Demonstrates tree data structure concepts and related operations.

▶️ How to Compile and Run
Prerequisites
Install a C compiler such as GCC on your system.

Compile a Program
Open a terminal in the project directory and run:

gcc Bubblesort.c -o Bubblesort
Run the Program
On Windows:

Bubblesort.exe
On Linux/macOS:

./Bubblesort
Compile Other Programs
Replace the filename and executable name with the program you want to run.

gcc Queue.c -o Queue
gcc conatctlist.c -o conatctlist
gcc conatctmanage.c -o conatctmanage
gcc stack.c -o stack
gcc tree.c -o tree
Run the corresponding executable after compilation.
